# Resume UI - Anish Mahato

A React-based resume application with PDF download functionality and profile image support.

## Features

- ✅ ATS-friendly resume layout
- ✅ Profile image upload and display
- ✅ PDF download functionality
- ✅ Clean, professional design
- ✅ Responsive layout

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Usage

1. Start the development server
2. Upload a profile image (optional)
3. Click "Download PDF" to generate and download your resume as PDF

## Technologies

- React 18
- TypeScript
- Vite
- jsPDF
- html2canvas
